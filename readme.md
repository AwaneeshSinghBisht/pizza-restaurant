# Pizza Restaurant Website

## Project Overview

This project is a responsive and accessible restaurant landing page built using **HTML5**, **CSS3**, and **Bootstrap 5**. It showcases a modern pizza restaurant with sections such as Home, About Us, Menu, Carousel, Gallery, Find Us, and Footer.

The website is designed to provide a clean user interface while maintaining responsiveness across desktops, tablets, and mobile devices.

---

## Features

* Responsive navigation bar
* Fixed header
* Hero section with background image
* About Us section
* Menu section
* Bootstrap image carousel
* Responsive image gallery using CSS Grid
* Google Maps integration
* Contact information
* Responsive footer
* Smooth scrolling
* Hover animations
* Semantic HTML structure
* Accessibility support using ARIA labels and descriptive alt text

---

## Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* Font Awesome
* Google Maps Embed

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or any modern web browser.
